# Reproduce Table 4

This is the exact sequence used to reconstruct the reported Table 4 numbers.

## 1) Environment

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 2) Optional CPT training

The CPT scripts are included for completeness; the public release does **not** require retraining.

```bash
export PYTHONPATH="$PWD/src/decoding"
python3 src/cpt/train.py configs/cpt_javanese.yaml
python3 src/cpt/train.py configs/cpt_sundanese.yaml
```

## 3) Checkpoint selection on the 1,000-utterance search set

```bash
bash src/selection/launch_ckptsel1k.sh jv 20k local 5
bash src/selection/launch_ckptsel1k.sh su 20k local 6
```

This evaluates 10k / 20k / 30k / 40k on the 1,000-utt search set and selects **20k**.

## 4) Final decode on the blind test set

```bash
export PYTHONPATH="$PWD/src/decoding"
python3 src/scoring/run_exp_mb.py configs/decode_javanese.yaml --split blind
python3 src/scoring/run_exp_mb.py configs/decode_sundanese.yaml --split blind
```

Expected Table 4 headline rows:

- Javanese: **51.87% WER**
- Sundanese: **54.72% WER**

## 5) Scoring and normalization

The scoring script performs the paper's text normalization before WER/CER computation:

- Unicode NFC
- lowercase
- punctuation stripping
- jiwer-based Levenshtein scoring

The same normalization is encoded in `eval.text_normalization` in the decode configs.

## Rescoring baseline (R2Q2b)

The public-release N-best rescoring baseline lives in
[`experiments/rescoring/README.md`](../experiments/rescoring/README.md). It uses
the same step-20k adapted MambaByte checkpoints and the same fusion coefficients
as the first-pass GFD method, but applies the LM post-hoc to a fixed Whisper
10-best list generated by sampling (`do_sample=True`, `temperature=0.7`,
`top_p=0.9`, `num_beams=1`, `num_return_sequences=10`, `seed=42`).

The three scripts are:

```bash
bash experiments/rescoring/run_whisper_nbest.sh --cuda 0 --lang jv \
  --out-dir experiments/rescoring/nbest/jv_t07_topp09_s42
bash experiments/rescoring/run_rescore_whisper_nbest.sh --cuda 0 --lang jv \
  --nbest-file experiments/rescoring/nbest/jv_t07_topp09_s42/jv_nbest.jsonl
bash experiments/rescoring/run_build_rescoring_report.sh
```

Repeat the same commands with `--lang su` and the SU N-best path
(`experiments/rescoring/nbest/su_t07_topp09_s42/su_nbest.jsonl`). The exact
parameter set is recorded in `configs/rescoring.yaml`, and the corrected
results are:

- JV: rescoring 60.53% WER, oracle 47.72% WER, GFD 51.87% WER
- SU: rescoring 63.21% WER, oracle 52.29% WER, GFD 54.72% WER
